# RepoManager — Git 仓库管理工具

## 概述

一个基于 Java Swing 的图形化 Git 仓库管理工具，支持多仓库切换、远程地址管理、拉取/推送/提交操作。

## 功能

| 功能 | 说明 |
|---|---|
| **多仓库管理** | 左侧列表管理多个 Git 仓库，双击或点击切换 |
| **远程地址管理** | 查看、添加、修改、删除远程仓库地址 |
| **Pull** | 拉取所有远程分支 |
| **Push** | 推送所有分支及标签到远程 |
| **Commit** | 自动暂存所有变更 → 输入提交信息 → 提交 |
| **Status** | 查看仓库当前状态 |
| **路径记忆** | 自动记住上次打开的仓库 |
| **数据持久化** | 仓库列表保存在 `repo.json`，支持手动编辑 |

## 技术栈

- **语言**: Java (JDK 21+)
- **GUI**: Swing
- **Git 操作**: `ProcessBuilder` 调用系统 git
- **数据存储**: `java.util.prefs.Preferences` + JSON 文件

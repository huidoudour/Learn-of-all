# Android应用管理工具 - 使用说明

## 📱 项目简介

这是一个基于Java Swing开发的Android应用管理工具，采用**左右分栏布局**（类似Android桌面启动器的抽屉模式），可以方便地管理Android设备和AVD模拟器上的第三方应用。

特别支持识别和标记包名包含 **"huidoudour"** 的应用。

### ✨ v3.0 新特性
- 🎨 **全新UI设计**：采用Google Material Design配色方案
- 🧠 **智能卸载**：根据用户ID自动选择卸载范围
- 💫 **美化交互**：悬停效果、彩色按钮、emoji图标
- 📊 **优化表格**：交替行颜色、特殊标记高亮

---

## ✨ 主要功能

### 1. 设备管理
- 🔍 自动检测所有已连接的Android设备和AVD模拟器
- 🔄 一键刷新设备列表
- 📱 支持多设备切换

### 2. 双栏应用展示
- **左栏**：显示用户0（主用户）的所有第三方应用（蓝色标题）
- **右栏**：显示其他用户（工作资料、多用户等）的应用（紫色标题）
- ⭐ 自动标记包名包含"huidoudour"的应用（橙色高亮）

### 3. 智能应用操作（带二次确认）

#### 🗑️ 卸载应用
- **主用户0的应用**：为【所有用户】卸载
- **其他用户的应用**：仅卸载【当前用户】
- 防止误操作，保护其他用户数据

#### 🧹 清除数据
- 清除指定用户的应用所有数据
- 包括登录信息、设置、本地文件等
- ⚠️ 不可恢复操作

#### 📦 清除缓存
- 清除指定用户的应用缓存
- 注意：当前ADB版本会同时清除数据

#### 📋 复制包名
- 快速复制应用包名到剪贴板
- 方便分享和记录

## 💡 智能卸载逻辑详解

### 场景一：卸载主用户0的应用

```
应用信息：com.example.app (用户0)

确认提示：
⚠️ 这是主用户（用户0）的应用

确定要为【所有用户】卸载应用 "com.example.app" 吗？
此操作将从所有用户空间中删除该应用，不可恢复！

执行命令：
adb -s <device> uninstall com.example.app

结果：
✅ 应用已从所有用户中卸载成功！
```

### 场景二：卸载其他用户的应用

```
应用信息：com.work.app (用户10)

确认提示：
ℹ️ 这是用户 10 的应用

确定要仅为【用户10】卸载应用 "com.work.app" 吗？
其他用户的应用将不受影响。

执行命令：
adb -s <device> shell pm uninstall --user 10 com.work.app

结果：
✅ 应用已从用户10中卸载成功！
```

### 优势
- ✅ 避免误删其他用户的应用
- ✅ 明确告知操作影响范围
- ✅ 符合Android多用户隔离原则

## ⚠️ 注意事项

### 前置条件
1. ✅ 确保系统环境变量中已配置ADB路径
   - 在命令行输入 `adb version` 验证
2. ✅ 启用设备的USB调试模式
   - 设置 → 开发者选项 → USB调试
3. ✅ 首次连接时需要在设备上授权USB调试

### 权限说明
- 部分操作可能需要root权限
- 系统应用无法通过此工具卸载
- 某些厂商定制系统可能限制部分功能

### 安全警告
- ⚠️ **卸载应用**：操作不可恢复，请谨慎操作
- ⚠️ **清除数据**：会删除所有应用数据，包括登录状态
- ⚠️ **清除缓存**：当前实现也会清除数据（ADB限制）

### 智能卸载说明
- ✅ 卸载主用户0的应用会影响所有用户
- ✅ 卸载其他用户的应用只影响该用户
- ✅ 系统会自动判断并给出相应提示

### 常见问题

**Q: 检测不到设备？**
- 检查USB线是否连接正常
- 确认USB调试已开启
- 在设备上授权USB调试许可
- 尝试重新插拔USB线

**Q: 应用列表为空？**
- 确认选择了正确的设备
- 点击"加载应用"按钮
- 检查设备是否有第三方应用

**Q: 操作失败？**
- 查看错误提示信息
- 确认ADB连接正常
- 检查应用是否为系统应用
- 尝试重启ADB服务：`adb kill-server` 然后 `adb start-server`

**Q: 为什么卸载非主用户应用时只影响一个用户？**
- 这是v3.0的智能卸载特性
- 使用 `--user` 参数精确指定用户
- 避免误删其他用户的数据

## 🔧 技术实现

### 核心技术
- **GUI框架**：Java Swing
- **通信协议**：ADB (Android Debug Bridge)
- **命令执行**：Runtime.exec()
- **数据处理**：BufferedReader解析ADB输出
- **UI美化**：自定义渲染器、配色方案

### 关键ADB命令
```bash
# 检测设备
adb devices

# 获取用户列表
adb -s <device> shell pm list users

# 获取第三方应用（指定用户）
adb -s <device> shell pm list packages -3 --user <userId>

# 卸载应用（所有用户）
adb -s <device> uninstall <package>

# 卸载应用（指定用户）
adb -s <device> shell pm uninstall --user <userId> <package>

# 清除应用数据/缓存（指定用户）
adb -s <device> shell pm clear --user <userId> <package>
```

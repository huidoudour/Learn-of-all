# Android应用管理工具 - v3.2 功能增强版

## 📱 v3.2 更新内容

### 🎯 核心改进

#### 1. ✅ 修复清除缓存命令

**问题：**
```bash
# 旧命令 - 错误地使用了clear（这会清除所有数据）
adb shell pm clear --user 10 com.example.app
```

**解决方案：**
```bash
# 新命令 - 使用正确的trim-caches清除缓存
adb shell pm trim-caches 999G
```

**说明：**
- `pm clear`：清除应用的所有数据和缓存（相当于重置应用）
- `pm trim-caches`：专门用于清除缓存文件，释放存储空间
- `999G`：指定要释放的目标空间大小（系统会自动清理直到达到目标）

**影响：**
- ✅ 现在清除缓存不会误删应用数据
- ✅ 更符合用户的预期操作
- ✅ 与Android系统的缓存管理机制一致

#### 2. 🚀 新增：启动应用功能

**功能描述：**
- 直接启动选中的第三方应用
- 模拟用户点击桌面图标的效果
- 适用于快速测试和调试应用

**技术实现：**
```bash
adb -s <device> shell monkey -p <package> -c android.intent.category.LAUNCHER 1
```

**使用方法：**
1. 右键点击应用 → 选择"🚀 启动应用"
2. 或双击应用 → 在对话框中点击"🚀 启动应用"按钮

**日志示例：**
```
[04:05:10] ℹ️  INFO: 执行启动应用命令: adb -s emulator-5554 shell monkey -p com.example.app -c android.intent.category.LAUNCHER 1
[04:05:11] ℹ️  INFO: ADB输出: Events injected: 1
[04:05:11] ✅ SUCCESS: ✅ 应用启动成功！ (com.example.app)
```

**应用场景：**
- 🔍 快速测试应用是否正常安装
- 🐛 调试应用启动问题
- ⚡ 批量测试多个应用

#### 3. ⏹️ 新增：强制停止应用

**功能描述：**
- 立即停止应用的运行
- 类似于Android设置中的"强制停止"
- 会停止所有Activity和服务

**技术实现：**
```bash
adb -s <device> shell am force-stop <package>
```

**使用方法：**
1. 右键点击应用 → 选择"⏹️ 强制停止"
2. 确认对话框中选择"是"
3. 或双击应用 → 点击"⏹️ 强制停止"按钮

**二次确认提示：**
```
确定要强制停止用户10的应用 "com.example.app" 吗？

这将立即停止应用的所有活动，可能导致数据丢失。
```

**日志示例：**
```
[04:05:20] ℹ️  INFO: 执行强制停止命令: adb -s emulator-5554 shell am force-stop com.example.app
[04:05:21] ℹ️  INFO: ADB输出: 
[04:05:21] ✅ SUCCESS: ✅ 应用已强制停止！ (com.example.app)
```

**应用场景：**
- 🐛 应用卡死或无响应时
- 🔄 需要重启应用以应用更改
- 🧪 测试应用的冷启动行为

---

#### 4. 💀 新增：杀死应用进程

**功能描述：**
- 更激进地终止应用进程
- 使用pkill命令杀死所有相关进程
- 比force-stop更彻底

**技术实现：**
```bash
adb -s <device> shell pkill -f <package>
```

**使用方法：**
1. 右键点击应用 → 选择"💀 杀死进程"
2. 在警告对话框中确认
3. 或双击应用 → 点击"💀 杀死进程"按钮

**二次确认提示（红色警告）：**
```
⚠️ 警告：此操作较为激进！

确定要杀死用户10的应用 "com.example.app" 的所有进程吗？
这会比强制停止更彻底，但可能导致系统不稳定。
```

**日志示例：**
```
[04:05:30] ℹ️  INFO: 执行杀死进程命令: adb -s emulator-5554 shell pkill -f com.example.app
[04:05:31] ℹ️  INFO: ADB输出: 
[04:05:31] ✅ SUCCESS: ✅ 应用进程已杀死！ (com.example.app)
```

**应用场景：**
- 🔥 应用严重异常，force-stop无效
- 🧹 需要彻底清理应用状态
- 🔬 深度调试和测试

### 💡 使用建议

#### 启动应用 🚀
- ✅ **推荐场景**：
  - 验证应用是否正确安装
  - 快速打开应用进行测试
  - 自动化脚本的一部分
  
- ⚠️ **注意事项**：
  - 应用必须有LAUNCHER Activity
  - 某些系统应用可能无法通过此方式启动

#### 强制停止 ⏹️
- ✅ **推荐场景**：
  - 应用界面卡死
  - 后台服务异常
  - 需要重新加载配置
  
- ⚠️ **注意事项**：
  - 会中断正在进行的任务
  - 未保存的数据可能丢失
  - 类似于从最近任务中滑动删除

#### 杀死进程 💀
- ✅ **推荐场景**：
  - force-stop无效
  - 应用有多个顽固进程
  - 需要彻底清理内存
  
- ⚠️ **注意事项**：
  - 可能导致系统不稳定
  - 某些系统进程可能被保护
  - 谨慎使用，优先尝试force-stop

### 🔧 技术细节

#### Monkey命令详解
```bash
adb shell monkey -p <package> -c android.intent.category.LAUNCHER 1
```
- `-p <package>`：指定包名
- `-c android.intent.category.LAUNCHER`：使用LAUNCHER类别
- `1`：发送1个事件（即点击）

#### Force-stop vs Pkill

**Force-stop (`am force-stop`)：**
- Android框架级别的操作
- 优雅地停止应用
- 清理Activity栈
- 通知系统应用已停止

**Pkill (`pkill -f`)：**
- Linux系统级别的进程管理
- 直接杀死进程
- 不经过Android框架
- 更彻底但更粗暴

### 📚 ADB命令参考

```bash
# 启动应用
adb shell monkey -p <package> -c android.intent.category.LAUNCHER 1

# 强制停止
adb shell am force-stop <package>

# 杀死进程
adb shell pkill -f <package>

# 卸载应用（所有用户）
adb uninstall <package>

# 卸载应用（指定用户）
adb shell pm uninstall --user <userId> <package>

# 清除数据（指定用户）
adb shell pm clear --user <userId> <package>

# 清除缓存
adb shell pm trim-caches <size>
```
